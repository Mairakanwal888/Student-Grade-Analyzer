# Student Grade Analyzer

A beginner-friendly student grade analysis project built with **Python and NumPy**.

## 📌 Project Overview

The Student Grade Analyzer takes student marks as input and performs basic analysis to understand their academic performance.

## 🚀 Features

* Store student marks
* Calculate average marks
* Find highest and lowest marks
* Analyze student performance
* Perform calculations using NumPy
* Beginner-friendly Python implementation

## 🛠️ Technologies Used

* Python
* NumPy
* Jupyter Notebook

## 📂 Project Structure

```text
Student-Grade-Analyzer/
│

```

## ▶️ How to Run

1. Download or clone this repository.
2. Open `StudentGradeAnalyzer.ipynb` in Jupyter Notebook or Google Colab.
3. Run the cells step by step.
4. Enter the required student marks when prompted.
